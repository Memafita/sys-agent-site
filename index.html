Boas práticas

Como usar este módulo melhor

  • Faça perguntas específicas: o que, para quem e em qual contexto.
  • Use “Montar resumo guiado” para juntar pistas de várias fontes e revisar com calma.
  • Salve uma tarefa sempre que encontrar uma oportunidade ou ideia acionável.
  • Se um link parecer fraco, abra a busca no navegador e compare duas ou três fontes antes de agir.

Sobre

Sobre o projeto

JARVIS BR v2 — mais maduro e mais confiável

Esta versão foi reorganizada para parecer menos “promessa” e mais “produto”. A linguagem está mais profissional, os recursos ficaram mais separados por função e os estados de erro/carga foram melhorados para passar mais confiança.

  • Busca com resumo guiado por referências quando possível.
  • OCR local com pré-processamento simples e exportação de texto.
  • Python carregado sob demanda para não deixar a abertura pesada.
  • Editor web com preview em sandbox e exportação de arquivo HTML.
  • Tarefas persistidas localmente para uso prático no dia a dia.

Instalação

Adicionar à Tela de Início no iPhone

  1. Abra esta página diretamente no Safari.
  2. Toque em Compartilhar.
  3. Procure a opção Adicionar à Tela de Início.
  4. Confirme o nome e toque em Adicionar.

Este pacote já vem pronto com manifest, ícones e service worker. Depois de hospedar na raiz do site, a experiência de instalação fica muito melhor.
