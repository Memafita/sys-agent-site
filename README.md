# JARVIS BR • Assistente Web Mobile

Pacote estático pronto para hospedagem.

## Arquivos principais
- `index.html`
- `manifest.webmanifest`
- `sw.js`
- `robots.txt`
- `icons/`
- `og-image.png`

## Como publicar
Suba **todos os arquivos** desta pasta para a raiz do seu host.

Funciona bem em:
- Netlify
- Vercel
- GitHub Pages
- hospedagem estática comum

## O que o projeto destaca
- busca guiada por fontes
- OCR local no navegador
- Python via Pyodide
- editor HTML/CSS/JS com preview
- tarefas salvas localmente
- PWA instalável

## Observação
Para usar como portfólio, mostre primeiro:
1. Python no navegador
2. OCR
3. editor web
4. experiência mobile-first
